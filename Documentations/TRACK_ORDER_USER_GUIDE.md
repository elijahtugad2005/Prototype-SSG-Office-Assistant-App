# Track My Order - User Guide

## 🎯 Quick Start

### How to Track Your Order

There are **3 ways** to access the order tracking feature:

---

## Method 1: From Homepage Quick Access

1. **Go to the Homepage** (`/`)
2. **Scroll to the Hero Section** (top of the page)
3. **Look for "QUICK ACCESS"** section on the right side
4. **Click on "Track My Order"** card (📦 icon)
5. You'll be redirected to the tracking page

```
┌─────────────────────────────────┐
│  QUICK ACCESS                   │
├─────────────────────────────────┤
│  📦 Track My Order         ←──  │ Click here!
│  👥 Student Engagement Portal   │
│  📅 Event & Activity Planning   │
└─────────────────────────────────┘
```

---

## Method 2: After Placing an Order

1. **Complete your order** on the Order page
2. **See the success screen** with your Order ID

## 🔍 Searching for Your Order

Once on the Track Order page, you have **2 search options**:

### Option A: Search by Order ID

1. **Select "Order ID"** tab (default)
2. **Enter your Order ID** (e.g., `ORD-1234567890-123`)
   - You received this when you placed your order
   - Check your email confirmation
3. **Click "Track Order"** button

```
┌─────────────────────────────────────────┐
│  [Order ID] [Email Address]             │
│                                         │
│  🔍 ORD-1234567890-123                  │
│                                         │

│  │  🔍 Track Order                 │   │
│  └─────────────────────────────────┘   │
└─────────────────────────────────────────┘
```

### Option B: Search by Email

1. **Select "Email Address"** tab
2. **Enter your email** (the one you used when ordering)
3. **Click "Track Order"** button


## ❌ Troubleshooting

### "Order not found" Error

**Possible reasons:**
1. **Incorrect Order ID** - Check for typos
2. **Wrong Email** - Use the email from your order
3. **Order not yet in system** - Wait a few minutes after placing order
4. **Order was deleted** - Contact officers

**Solutions:**
- Double-check your Order ID (copy-paste if possible)
- Verify email address spelling
- Try searching by the other method (ID vs Email)
- Contact student government officers for assistance

### Order Status Not Updating

**Possible reasons:**
1. Officers haven't updated status yet
2. Browser cache issue
3. Network connectivity problem

**Solutions:**
- Refresh the page (F5 or Ctrl+R)
- Clear browser cache
- Try again in a few minutes
- Contact officers if status hasn't changed in 24 hours

## 💡 Tips & Best Practices

1. **Save Your Order ID**
   - Screenshot the success screen
   - Save the confirmation email
   - Write it down

2. **Check Regularly**
   - Status updates happen in real-time
   - Check back periodically for updates

3. **Prepare for Pickup**
   - When status is "Completed", go to pickup location
   - Bring valid ID and Order ID
   - Check pickup hours

4. **Contact Officers**
   - If status is stuck for too long
   - If you have questions about your order
   - If you need to cancel or modify
